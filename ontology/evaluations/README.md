# Evidence-based situational prompt evaluations

This registry stores actual **observations** of a specified prompt generation under documented conditions and testable outcome evidence. It contains no fabricated tests, no automatic grading by prompt length, and no inferred success from wording alone.

An evaluation identifies a `FAMILY-xxxx` and explicit semantic version, references formal `INTENT-xxxx` objectives, records environmental conditions and outcome basis, and contains supporting evidence. Claims may be `satisfied`, `not_satisfied`, or `indeterminate`; unknown results stay absent, not guessed.

There are **no observed evaluation records yet**: no controlled execution of these prompt generations has been provided. All 24 versions remain independently accessible and selectable, but publishing them is not evidence they achieve their goals.

The independently published `EVAL-DIM-0001`–`EVAL-DIM-0007` dimensions are evaluation vocabulary, not observational results. See [evaluation schema](../../schema/situational-evaluation.schema.json).
