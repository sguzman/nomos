## C++ → Rust coverage and limits

Lite emphasizes baseline fidelity, Rust builds/tests, privacy, data round-trip integrity and backwards compatibility. Full adds extensive regression/target matrices, CI, documentation, versioning, MVP gates and acceptance evidence.

**Unrepresented language-specific atomic obligations (review gaps):** destruction timing and RAII, object ownership and aliasing, C++ exceptions and Rust error translation, templates/concepts/overload resolution, polymorphism and RTTI, layout and vtables, C++ ABI/FFI interoperation, atomics and memory-model parity. The generic rules are useful but do not *by themselves* require verification of these behaviors.

## Python → Rust coverage and limits

Lite emphasizes observable behavior, regression tests, repository safety and data serialization/round-trip. Full adds CI, platform test matrices, release/packaging discipline, versioning, documentation, progress and fidelity gates.

**Unrepresented language-specific atomic obligations (review gaps):** dynamic typing and reflection, truthiness and coercions, integer/float/decimal behavior, Unicode/text and exception traces, iterator/generator/context-manager protocols, mutability and object identity, imports and package/plugin behavior, asyncio/threading/GIL assumptions, Python bindings or extension APIs. Asynchronous behavior and data interchange require explicit baseline decisions for a real project.

## Review workflow

Use the [public catalog](https://sguzman.github.io/nomos/) → Profiles only → Browse members. The user may amend and explicitly confirm individual rule selections. Selection approval, finalization, export and actual use remain separate later choices. This draft request did not authorize publishing additional language-specific atoms, porting external repositories, or modifying the existing C-to-Rust profiles.

Project type facets `cpp_to_rust_port` and `python_to_rust_port` are now recognized in the ontology as Rust software ports; they do not make C-scoped rules applicable to another source language.
