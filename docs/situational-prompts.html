NOMOS / SITUATIONAL PROMPTS

Instructions for a specific moment.

Unlike a permanent rule or a rule-profile preset, a situational prompt is deliberately invoked for one conversation event. Browse each situation's trigger, applicability, intended behavior, and known hazards. All eight families preserve separately selectable v1, v2 and v3 text. The original v1 remains the default; choose a version before copying. Nothing is automatically invoked.
